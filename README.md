# Art em Foco 🎨

Editor de desenho e animação web, desenvolvido pela **Cidio Sistemas**.

## Estado do projeto
Protótipo em desenvolvimento. O editor HTML da versão 8 será incorporado ao repositório como `index.html` após validação do arquivo original.

## Funcionalidades planejadas / prototipadas
- Pincéis, borracha e transparência
- Camadas e modos de mesclagem
- Balde de tinta e seleção
- Gestos de dois dedos para zoom e movimentação
- Zoom de precisão até 6400%
- Animação quadro a quadro com onion skin e reprodução
- Interface responsiva para dispositivos móveis

## Estrutura inicial
- `index.html`: aplicativo web (a adicionar)
- `README.md`: documentação

## Execução
Após adicionar `index.html`, abra o arquivo no navegador para testar localmente.

## Aviso
Projeto experimental. Recursos devem ser validados em navegadores móveis antes de uso em produção.
